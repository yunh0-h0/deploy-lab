# 기본 저장·조회 동작 스펙

- trim 후 JavaScript 문자열 length 기준 1~200자. 기본 경계 실험은 한글·영문으로 한다.
- 서버 rules.js와 프런트 src/rules.js에 같은 규칙을 반영한다. 서버 검증이 최종 판단이다.
- 오류는 400, DB에 행을 추가하지 않는다. 정상 입력은 201, 목록·새로고침·다른 브라우저에서 확인한다.
- 서버·화면 RELEASE도 작업명을 구별할 값으로 바꿔 확인한다. 버전 문자열만으로 커밋 동일성을 확정하지 않는다.
- DB 구조 변경 없음. 기존 메모 보존. SQL/API 계약은 [서비스 원본](../../../service.md) 참조.

## 확인 조건
1. 공백·문자열 아닌 값 거절.
2. 0자 거절, 1자 성공, 200자 성공, 201자 거절.
3. 서버 검증을 프런트 우회 직접 API 요청으로 확인한다.
4. 실제 화면에서 경계 안내·오류·저장·재조회 확인.
5. 배포 뒤 공개 API로 같은 검사·휴대폰 화면 확인. 커밋·시각을 verification.md에 남긴다.
